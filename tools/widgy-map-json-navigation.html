בדיקת מהירות עם המפה החיצונית

עותק קטן עם שתי לשוניות: Home מציג את מפת הבדיקה המלאה, ו־Calendar מציג כיתוב קבוע. מקור התמונה מוגדר מראש לפי ה־JSON שיוצא בהצלחה.

מכין את עותק הבדיקה…

הורדת קובץ לייבוא
  1. העתק את הווידג׳ט. ב־Widgy בחר Import → Import URL Or JSON והדבק. שם העותק: Widgy Map JSON Navigation 1.
  2. הצב אותו במקום שבו ביצעת את בדיקות המעבר הקודמות, והמתן שהמפה תיטען בשלמותה.
  3. עבור שלוש פעמים בין Home ל־Calendar, ובדוק אם החזרה למפה מהירה.
  4. המתן דקה בלי לגעת, ועבור שוב ל־Calendar ובחזרה. דווח אם החזרה הראשונה איטית או שהמפה נעלמת.

כל ההגדרות מוכנות. אין צורך להוסיף דבר ב־{} או לפתוח את מקור התמונה בעורך.

זו מפה קבועה לצורך בדיקת המהירות. מיקום אישי, עדכון יום/לילה ואירועי יומן אינם חלק מהעותק הזה. הצלחה בבדיקה הקטנה עדיין דורשת בדיקה בווידג׳ט המלא.
