WIDGY · MAP FIVE MINUTE 1

בודקים מהירות יחד עם עדכניות.

בדיקה נפרדת עם מקור התמונה הרגיל, מיקום חי וחותמת MAP TIME. כתובת המפה משתנה לפי מקטעים של חמש דקות, כדי לבדוק אם אפשר לשמור תמונה לשימוש חוזר בין עדכונים.

מכין את עותק הבדיקה…

הורדת קובץ לייבוא
  1. שמור את עותק הבדיקה הקודם. העתק את Map Five Minute 1, וב־Widgy בחר Import → Import URL Or JSON והדבק.
  2. שייך את העותק החדש לווידג׳ט הנבדק במסך הבית. הגדרות התמונה כבר מוכנות. המתן למפה ולסימון המיקום ורשום את MAP TIME.
  3. עבור Calendar → Home פעמיים ובדוק אם המעבר מהיר ואם השעה חוזרת לאחור.
  4. השאר על Calendar כשש דקות, חזור ל־Home ובדוק את השעה ואת מהירות החזרה הראשונה. אל תלחץ על רענון ידני במהלך הבדיקה.

חמש דקות הן חלוקה של כתובת התמונה, לא הבטחה ש־Widgy תרענן בזמן קבוע. שינוי מיקום עשוי לשנות את הכתובת מוקדם יותר. ייתכן עיכוב כשהאפליקציה טוענת מפה חדשה; הבדיקה נועדה לגלות אם האיזון מתאים. השעה שבתמונה מציינת את זמן יצירתה ואינה שעון מתקתק.
