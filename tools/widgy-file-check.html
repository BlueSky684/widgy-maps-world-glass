בדיקת קריאת קובץ

זהו קובץ טקסט זעיר עם 13 תווים. הוא מיועד לבדיקה ב־Map Check 3 בלבד.

  1. שמור את widgy-file-check.txt באותה תיקייה מקומית שבה שמרת את קובץ המפה.
  2. ב־Map Check 3, פתח Edit Widget ← {} ← map_png_base64 ← Files, ובחר את קובץ הבדיקה.
  3. צא מהעורך ופתח שוב את פרטי הווידג׳ט. שלח צילום של שורת DATA.

אם הקובץ נקרא, אמור להופיע OTHER | 13. אם לא נטען תוכן, יופיע EMPTY | 0. המפה עצמה תהיה ריקה בבדיקה הזאת, כי הקובץ מכיל טקסט רגיל.
