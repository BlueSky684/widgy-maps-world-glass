הורדת קובץ לייבוא
  1. העתק, וב־Widgy פתח Import → Import URL Or JSON והדבק.
  2. ייבא כעותק נוסף בשם Widgy Calendar Direct Dots 1.
  3. בדוק שנקודות האירועים מופיעות בחודשים שבהם יש אירועים, ושהחצים מחליפים חודשים כרגיל.
  4. השווה כמה מעברים בין Home ל־Calendar מול Consolidated Home Calendar 1, באותו סלוט ובאותה רשת.

לפני שמאמצים את הגרסה: בדוק גם ששינוי באירוע נקלט בנקודות לאחר סנכרון היומן, המתנה של דקה ורענון הווידג׳ט. אם חסרים סימונים, חזור לעותק המאוחד ודווח — זו בדיקת תאימות לפני בדיקת מהירות.
