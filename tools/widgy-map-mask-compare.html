המסכה על המפה האמיתית

שני מצבים באותו עותק: MASK מציג את המפה המורכבת משכבות קבועות ומסכות קטנות; ORIGINAL מציג את תמונת המקור. שתי המפות מחושבות לאותה שעה כדי להשוות צבעים, תאורה וקווי חוף.

מכין את עותק ההשוואה…

הורדת קובץ לייבוא
  1. ייבא ב־Widgy דרך Import → Import URL Or JSON. יופיע עותק נפרד בשם Widgy Map Mask Compare 1.
  2. שייך את עותק ההשוואה לווידג׳ט הנבדק במסך הבית. שמור את Map Five Minute 1 לחזרה בהמשך.
  3. המתן לטעינה הראשונה, עבור בין MASK ל־ORIGINAL ושלח צילום מכל מצב. אין צורך לשנות הגדרות בעורך.

השעה קבועה בכוונה. בבדיקה הזאת אין סמן מיקום והפינות ישרות בשני המצבים. קודם בודקים את המראה בפועל; רענון חי ומהירות טעינת מסכה חדשה יהיו השלב הבא. הפיצול עדיין ניסיוני.
