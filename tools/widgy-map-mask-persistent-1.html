מכין ובודק את מבנה העותק…

שמירת קובץ JSON פתיחת הדף ב־Chrome
  1. העתק את הקוד וב־Widgy בחר Import URL Or JSON והדבק.
  2. ודא ששם העותק הוא Widgy Map Mask Persistent 1, ואל תמחק את Live 1.
  3. לאחר ששני חלקי המפה הופיעו בפעם הראשונה, עבור חמש פעמים בין Home ל־Calendar וחזרה.
  4. בדוק אם המפה חוזרת שלמה, או שעדיין רואים קודם את N ורק אחריו את D. הקלטה קצרה תאפשר להשוות.

אין צורך לשנות הגדרות. מסך Calendar נשאר ריק בכוונה. מקורות התמונות, מצבי השילוב, כפתורי הניווט ומשתני חלון חמש הדקות נשארים כמו ב־Live 1.

מה הבדיקה משנה?

קבוצות היום והלילה והרקע מועברות ללא שינוי לקבוצת מפה קבועה, מתחת לשתי הכרטיסיות. קבוצה זו אינה מוסתרת על ידי כפתורי הניווט. אין שינוי בקובצי המפה, במסיכות, בשירות הרענון או בהגדרות האנימציה. ההגדרה אינה מבטיחה שמערכת ההפעלה תשמור תמונות בזיכרון, תטען שתי מסיכות יחד או תרענן אותן אוטומטית כל חמש דקות. זו בדיקה של מבנה השכבות, לא אישור שהתקלה נפתרה.
