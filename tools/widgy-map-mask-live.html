הורדת קובץ לייבוא
  1. ייבא דרך Import → Import URL Or JSON ושייך את Widgy Map Mask Live 1 לווידג׳ט הנבדק במסך הבית.
  2. המתן לטעינה הראשונה ושלח צילום שבו שתי חותמות הזמן מוצגות.
  3. השתמש בטלפון כרגיל ועבור בין Calendar ל־Home. כשהחותמות מתקדמות, דווח אם החזרה למפה נשארה מהירה ואם שני הזמנים תואמים.

הזמן מצוין לפי ישראל ובמקטעים של חמש דקות, כש־Widgy מחשב את המקור מחדש; זו אינה הבטחה לרענון בכל חמש דקות. הפס התחתון זמני. עדיין אין סמן מיקום, וה־Calendar כאן ריק לצורך הבדיקה. שמור את Five Minute 1 ואת Compare 1.
