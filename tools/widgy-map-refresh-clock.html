מכין את עותק הבדיקה…

הורדת קובץ לייבוא
  1. שמור את Map Stable GPS 1 המהירה. העתק את הבדיקה החדשה, וב־Widgy פתח Import → Import URL Or JSON והדבק.
  2. המתן למפה עם סימון המיקום ועם השורה MAP TIME בתחתיתה. השעה היא לפי שעון ישראל. זכור או רשום אותה; היא שעת יצירת התמונה ואינה אמורה לתקתק.
  3. עבור ל־Calendar, השאר את הטלפון ארבע דקות בלי לגעת בו, ואז חזור ל־Home כרגיל.
  4. כתוב לי מה השעה שמופיעה בתמונה עכשיו, האם השתנתה, והאם המעבר נשאר מהיר. אין צורך ברענון ידני, בייבוא נוסף או בצילום וידאו.

המיקום, הכתובת היציבה וזמן השמירה הזמנית נשמרים. יש רק פס אבחון זמני על תמונת המפה; הוא אינו חלק מהעיצוב הסופי. אם השעה אינה משתנה, נדע שבאותה חזרה לא הוצגה תמונה שנוצרה מאוחר יותר. זו עדיין אינה הוכחה שהתמונה לא תתעדכן כלל בהמשך.
