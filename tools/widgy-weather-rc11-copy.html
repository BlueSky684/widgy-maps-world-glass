Widgy Weather RC1.1

גרסת בדיקה לתיקון התאמת נתוני הצעדים והקלוריות בין התצוגות. הצעדים ב־Home וב־Health מחוברים למקור היומי של הטבלה; הקלוריות ב־Health מחוברות ישירות למקור של הטבעת. השמש הבודדת בכרטיס מזג האוויר ב־Home הוקטנה ב־15% למראה עדין יותר.

מסך Home המלא עם המפה מגוגל באיכות המקורית.

שם הווידג׳ט לאחר הייבוא: Widgy Weather RC1.1.

מקורות נתוני Weather: Open-Meteo, ברישיון CC BY 4.0. מקור איכות האוויר: Copernicus CAMS דרך Open-Meteo. הנתונים מעוגלים ומעוצבים לתצוגה.

מכין את הווידג׳ט להעתקה…

ההעתקה בשורות מופעלת כברירת מחדל, כפי שעבדה אצלך. כל תוכן הווידג׳ט נשמר.

לאחר ההעתקה, לחץ לבדיקה שהתוכן הועתק במלואו.

אימות באמצעות הדבקת הטקסט

הדבק כאן את הטקסט שהעתקת ולחץ על אימות.

לחץ ״בחר הכול״, ואז בחר ״העתק״ בתפריט המכשיר.

  1. אם חבילת Widgy Fonts כבר מותקנת, אפשר להמשיך ישירות להעתקה. אחרת, התקן אותה תחילה מהשיחה.
  2. פתח ב־Chrome ולחץ Copy Full JSON.
  3. ב־Widgy בחר Import → Import URL Or JSON והדבק. אפשר גם להוריד את הקובץ ולייבא דרך Files.
  4. ב־Manage → Large #1 בחר Widgy Weather RC1.1 במקום הגרסה הנוכחית.
  5. פתח Health והשווה את הצעדים והקלוריות למספרים בשורה של היום בטבלה. בדוק גם שהצעדים ב־Home תואמים. שמור את RC1 להשוואה.

הקישור אישי ומאפשר גישה לקובץ. שמור אותו אצלך.
