מתמקדים בטעינת המפה.

עותק של Lean 1 עם שינוי יחיד במפה: כשמיקומך אינו משתנה, כתובת התמונה נשארת קבועה כדי לאפשר שימוש חוזר בתמונה. המפה נשארת באיכות המלאה, ונתוני המיקום ממשיכים להגיע מאותו מקור.

מכין את העותק האישי…

הורדת קובץ לייבוא
  1. העתק, וב־Widgy פתח Import → Import URL Or JSON והדבק. השם: Widgy Map Cache URL 1.
  2. ייבא כעותק נוסף והצב באותו מקום שבו בדקת את Home Sync Map Lean 1.
  3. המתן למפה ולסימון המיקום. עבור כמה פעמים Calendar → Home, ואז חזור על המעבר כעבור כשתי דקות.
  4. האם התקיעות פחתו? האם הן חוזרות אחרי ההמתנה? דווח בנפרד אם המפה או הסימון חסרים.

השרת כבר מגביל את טריות התמונה לעד דקה. עדיין צריך לוודא כיצד Widgy משתמש במטמון ומרענן יום/לילה עם הכתובת הקבועה. זו בדיקה, לא הבטחה שהעיכוב תוקן. שאר רכיבי Home עדיין אינם מוחזרים.

ב־Home מופיעים רק המפה והניווט, עם קואורדינטות ליד הסימון. זו אותה תצוגה מצומצמת כמו ב־Lean 1.
