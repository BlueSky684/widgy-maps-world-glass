הורדת קובץ לייבוא
  1. לחץ על העתקת עותק האבחון.
  2. ב־Widgy פתח Import → Import URL Or JSON.
  3. הדבק וייבא כעותק נוסף. שייך זמנית לאותו סלוט שבו בדקת את perf-5.
  4. לאחר הטעינה הראשונה, עבור שלוש פעמים Home → Calendar → Home באותו חיבור רשת. האם החזרה ל־Home מהירה משמעותית?
  5. לאחר הבדיקה חזור לווידג׳ט הרגיל שלך.

העותק כולל את החיבור הפרטי ליומנים שלך. שמור אותו לעצמך.
