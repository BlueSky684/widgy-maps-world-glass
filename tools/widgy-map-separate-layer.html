המפה כשכבה נפרדת.

אותה מפה חיה ובאותו גודל, מחוץ לקבוצת Home. לשוניות Calendar, Weather ו־Fitness מכסות אותה כשהן מוצגות. בודקים אם שינוי המבנה משפיע על ההמתנה במעבר.

הורדת קובץ לייבוא
  1. העתק, וב־Widgy פתח Import → Import URL Or JSON והדבק. השם: Widgy Map Separate Layer 1.
  2. ייבא כעותק נוסף והצב באותו מקום שבו בדקת את Home Sync Map Lean 1.
  3. ודא שהמפה והמיקום מופיעים ב־Home בגודל ובמקום הרגילים. עבור ל־Calendar: המפה צריכה להיות מכוסה לגמרי. כך גם ב־Weather וב־Fitness.
  4. עבור שלוש פעמים Calendar → Home וחזרה. האם ההמתנה התקצרה, נשארה דומה או התארכה? ציין אם Calendar האטה או אם המפה חסרה.

ב־Home נשארים רק המפה והניווט. זו בדיקה זמנית; אין עדיין הוכחה שהפרדת השכבה שומרת את המפה טעונה ב־Widgy. אם התצוגה שגויה או איטית יותר, חזור ל־Lean 1.
