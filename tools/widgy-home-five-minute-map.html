אותה מפה מתעדכנת, בתוך Home המלא.

בעותק המפה הקטן דיווחת שהזמן מתקדם והמעברים יחסית מהירים. כאן משולב אותו מנגנון בממשק Home המלא, עם היומן, מזג האוויר ונתוני הכושר. זו בדיקת שילוב: המהירות בווידג׳ט המלא עדיין טעונה בדיקה.

הורדת קובץ לייבוא
  1. שמור את עותק Map Five Minute 1 המהיר. העתק את העותק החדש וב־Widgy בחר Import → Import URL Or JSON והדבק.
  2. ייבא כעותק נוסף בשם Widgy Home Five Minute Map 1, ושייך אותו לווידג׳ט הנבדק במסך הבית. השאר את הגדרות התמונה המוכנות.
  3. אחרי הטעינה הראשונית, בדוק שהמפה, השעון, מזג האוויר, הכושר והיומן מופיעים כרגיל. שם העיר במפה נשאר זמנית קואורדינטות; העיר ב־Calendar משתמשת במקור המובנה ויש לבדוק שהיא נכונה.
  4. השתמש כרגיל ועבור Calendar → Home וגם בין חודשים ביומן. האם המעברים עדיין יחסית מהירים, והאם MAP TIME מתקדם לאורך השימוש? דווח אם המפה נעלמת, השעה חוזרת לאחור, או האיטיות חזרה עם הממשק המלא.

כתובת הזמן מחולקת למקטעים של חמש דקות כש־Widgy מחשבת אותה. אין כאן טיימר או הבטחת רענון: שינוי בקואורדינטות יכול לשנות את הכתובת מוקדם יותר, וטעינת תמונה חדשה עדיין עלולה לעכב מעבר. השעה שבתמונה מציינת את זמן יצירתה. אין צורך בהמתנה מתוזמנת או ברענון ידני.

העיצוב, איכות המפה ומקורות מזג האוויר והכושר נשמרים. כרטיסיות WEATHER ו־FITNESS נשארות בשלב הפיתוח הקודם שלהן. שורת MAP TIME היא אבחון זמני; החזרת שם העיר למפה היא שלב נפרד.
