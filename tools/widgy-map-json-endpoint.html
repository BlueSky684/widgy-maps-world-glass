בדיקת מקור תמונה חיצוני

המפה בבדיקה קבועה, בגודל המלא 3306 × 1558. המטרה כרגע: לראות שהיא נשארת מוצגת ושאפשר לייצא את הווידג׳ט. לאחר מכן נבדוק עדכון דרך אותו קישור.

בודק שהמקור זמין…

  1. צור ב־Widgy ווידג׳ט חדש בגודל Large, והוסף שכבה מסוג Image.
  2. בלשונית התמונה בחר Web And Maps → JSON Endpoint.
  3. הדבק את הקישור שלמעלה בשדה כתובת המקור, והפעל את הבדיקה. בבורר הנתונים בחר את השדה image שמכיל כתובת תמונה, ואשר.
  4. שמור וצא מהעורך. בדוק שהמפה מופיעה גם מחוץ לעורך. היכנס וצא שלוש פעמים.
  5. נסה Share Widget → Export As JSON. אם מתקבלת שגיאה, שמור את הנוסח שלה.

ב־{} לא מוסיפים משתנים. הקישור הזה מיועד לשדה JSON Endpoint בשכבת התמונה; הוא אינו קובץ ווידג׳ט לייבוא.

בחר את המפתח image, לא את revision. זו בדיקת מפה קבועה ללא מיקום אישי. השעה ומצב היום/לילה עדיין אינם מתעדכנים.
