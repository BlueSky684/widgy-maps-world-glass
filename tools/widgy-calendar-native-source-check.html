בדיקת מקור Calendar

קובץ קטן שמכיל שכבת Calendar ושדות יומן חיים, לצורך השלמת ההטמעה של העיצוב שאישרנו.

  1. פתח ב־Safari, העתק וייבא ב־Widgy כווידג׳ט נוסף בשם Widgy Calendar Native Source Check.
  2. פתח לעריכה את השכבה Native Calendar · Enable Event Indicators והפעל הצגת אירועים/נקודות בהגדרות היומן. בחר תחילת שבוע ביום ראשון.
  3. שתף את הווידג׳ט כ־JSON ושלח את הקובץ בחזרה לשיחה. צילום של מסך הבדיקה יעזור גם לאמת את שדות האירועים שמתחת ללוח.
